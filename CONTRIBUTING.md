# Contributing to MGP

Thank you for your interest in contributing to the Morpho‑Semantic Governance Protocol (MGP).

MGP is a standards‑grade specification. Contributions must preserve clarity, determinism, and morphosemantic rigor.

---

## 1. How to Contribute

1. **Discuss first**  
   Open an issue for any significant change. Early discussion prevents unnecessary work and ensures alignment with the protocol’s philosophy.

2. **Follow the RFC process**  
   All normative changes MUST be made through the RFC mechanism.  
   See `rfcs/` for examples and structure.

3. **Respect the linguistic contract**  
   All naming, grammar, and ontology changes MUST maintain morphosemantic determinism (RFC‑0001).

4. **Keep it minimal**  
   Avoid unnecessary complexity. The protocol favors clarity and simplicity.

---

## 2. Development Process

- Normative changes require:
  - a new RFC **or**
  - a version bump to an existing RFC (RFC‑0007)

- The substrate structure is fixed at **ten canonical top‑level domains** (RFC‑0005)

- New top‑level domains are prohibited

- Extensions MUST follow RFC‑0006

- Domain boundaries MUST follow RFC‑0009

---

## 3. Non‑Normative Contributions

You may contribute:

- examples
- diagrams
- clarifications
- documentation improvements
- test substrates
- discussions and proposals

These do not require a new RFC unless they alter normative behavior.
